# Отчёт о проверке версии 0.1.0

Это исторический отчёт первой версии. Исправления и актуальные проверки версии 0.2 описаны в [REGRESSION_020_RU.md](REGRESSION_020_RU.md).

Проверки выполнены 30–31 октября 2026 года на Windows x64 в каталоге `D:\Atlas тестовое`. Это результаты проверки прототипа, а не гарантия правильности сравнения любых договоров.

## Автоматические проверки

Итоговый прогон: **34 проверки прошли** — 32 проверки сравнения/API/подписей/задач и 2 проверки политики исполнения моделей.

| Область | Проверено |
|---|---|
| Точный diff | Одинаковый текст, одна цифра/буква, отрицание, похожие символы разных алфавитов, длинный фрагмент с изменением в конце |
| Сопоставление | Перемещение, разделение абзаца, перенос строки, различия строк PDF; сходство эмбеддингов не скрывает точное изменение |
| Категории | Суммы, реквизиты, количество отдельно от цены; неизменённые сущности рядом не добавляют ложную категорию |
| Таблицы | Добавление строки одним событием, изменение ячейки, добавление столбца, объединение ячеек |
| Извлечение | DOCX с переносами и таблицей, отказ при неразрешённых исправлениях, неполнота сканированного PDF |
| Подписи | RSA и ECDSA, подмена документа, истёкший сертификат, повреждённый контейнер, отсутствие сертификата, неподдерживаемый алгоритм, PDF с последующей ревизией |
| API | Создание и выполнение, результат и preview, три отчёта, heartbeat, удаление/404, неверный формат, повреждённый PDF |
| Задачи | Очистка по сроку, отмена процесса, запись этапа при открытом читателе Windows |
| Модели | Искусственная ошибка OOM с повтором на CPU; сохранение позиций сущностей в длинном тексте |

Команды для повторения из корня проекта после установки зависимостей разработки:

```powershell
python -m pytest tests/test_diff.py tests/test_extract.py tests/test_signatures.py tests/test_api.py tests/test_jobs.py -q
python -m pytest tests/test_model_policy.py -q
```

Для второй команды нужны зависимости моделей. Pytest не является обязательной зависимостью обычного запуска. Тесты используют искусственные документы и сертификаты.

## Реальные преобразования и отчёты

`scripts/verify_demo.py` проверил все **9 направленных сочетаний DOC, DOCX и PDF**. В каждой паре найдены пять внесённых изменений: сумма договора, вид дней, цена ячейки, добавленная строка, цифра ИНН. Добавленная строка учитывается один раз. Три сравнения неизменённых DOC/DOCX/PDF дали ноль событий.

Выполнены реальные преобразования LibreOffice Portable. Отчёты PDF, DOCX и JSON получены через API; PDF и преобразованный в PDF Word-отчёт отрисованы для визуальной проверки кириллицы, длинных фрагментов и разбиения страниц. Отчёты сохраняют сведения и после удаления задачи. Исходные контрольные документы и ожидаемые результаты: `tests/fixtures/`.

Веб-интерфейс проверен на загрузке пары Word, восстановлении задачи по URL, выборе изменений и подсветке двух версий. Снимок интерфейса: `interface.jpg`. Примеры документов целиком искусственные.

## Модели и память

Обе закреплённые модели реально загружены и проверены на CPU и CUDA. MiniLM возвращает векторы размерности 384. GLiNER выделяет организации и сумму; диапазоны проверены по исходной строке, включая сущность в конце длинного фрагмента.

На доступной NVIDIA RTX 4070 измерены следующие пики памяти аллокатора PyTorch:

| Модель | Выделено, МиБ | Зарезервировано, МиБ |
|---|---:|---:|
| MiniLM | 465,39 | 488 |
| GLiNER | 1144,18 | 1214 |

Это память аллокатора, без полного CUDA-контекста и других приложений. Проверка на реальной карте с 2–3 ГБ пока не выполнена. Бюджет приложения — 2304 МиБ, модели исполняются последовательно, предусмотрен переход на CPU. Реальный GPU OOM не провоцировался; поведение при OOM проверено инъекцией ошибки.

Холодный запуск включает чтение весов и занимает десятки секунд. Скорость всего документа в миллисекундах не заявляется. Финальный сквозной сценарий проверяется `scripts/verify_release.py`: пять событий и фактическое использование ИИ, затем получение и отрисовка всех отчётов.

## Переносимость, автономность и сеть

Выполнена физическая копия файлов в `work/Копия проекта с пробелами` на этом же ПК: локальные Python/uv, исходники, vendor, веса и установочный материал конвертера. Готовые виртуальные окружения не переносились. Окружения созданы заново; все три приложения запущены на отдельных портах и возвращают собственный идентификатор установки.

Затем копия повторно запущена с `UV_OFFLINE=1` и недоступным HTTP/HTTPS-прокси, с исключением localhost. Все три приложения готовы без повторного скачивания. В этом режиме реальное сравнение вернуло **5 событий и `ai_state: used`**. Процессы временной копии после проверки остановлены. Временная копия и дублирующие загрузки оставлены: автоматическая проверка разрешений отклонила их удаление.

Три основных сервиса ответили по localhost и IP сетевых интерфейсов этого ПК. Доступ с другого физического ПК, настройки его брандмауэра и ограничения браузера в чужой сети не проверены. Скрипты не меняют правила брандмауэра.

## Границы подтверждённого результата

- Не проверены чистая установка на другом физическом Windows-ПК и демонстрационный старый ноутбук. Их нужно проверить перед встречей, особенно доступный диск, драйвер и время холодного запуска.
- Нет OCR; изображения с текстом и сканированные страницы помечаются как непроверенные. Таблицы и порядок чтения сложных PDF могут восстанавливаться неполно, о чём выдаются ограничения.
- Не подтверждён исчерпывающий набор сложных многостраничных таблиц, колонтитулов, сносок и неоднозначных повторяющихся пунктов реальных договоров. Нужен отдельный размеченный набор компании; модель не заменяет такую проверку качества.
- ГОСТ и доверие/отзыв сертификатов не заявлены как проверенные. Проверки поддерживаемых алгоритмов выполнены на искусственных сертификатах; реальные контейнеры Диадока требуют отдельной проверки.
- Согласованные ограничения: оформление только по абзацам/явным переносам Word–Word; нет истории и авторизации. Доступ по непредсказуемому ID не заменяет разграничение доступа.

Машинные журналы воспроизведения находятся в `work/verification/matrix.json`, `work/models-*.json`, `work/portability-check.json`, `work/network-check.json` и `work/end-to-end-ai.json`. Они содержат только искусственные тестовые данные.

# Проверка выпуска 0.3.0

02.11.2026. Проверены изменения после перекрёстного аудита 0.2.x.

## Основные результаты

- Через работающий HTTP API повторены все 36 направленных сочетаний шести локальных тестовых файлов. Все задачи завершились; скачаны 108 отчётов.
- 25 сочетаний читаемых документов: девять контролей одинакового содержимого дали ноль; исходник ↔ первая изменённая редакция — 20 событий независимо от DOCX/PDF; исходник ↔ вторая — 24; первая ↔ вторая — 43. Числа симметричны при обмене сторон.
- Прежние 28/32 события для смешанных форматов устранены. Каждая редакция извлекается из собственного файла, а не размечается по другой редакции.
- Прежние 44/48 событий двух изменённых редакций заменены 43: перемещённая и отредактированная строка — один родитель с изменением ячеек внутри. Это не пропуск правки и не требование одинакового счётчика для всех договоров.
- Независимый контрольный список (20 условий первой редакции, 24 признака второй, их сочетание при сравнении изменённых редакций) сохранил все проверяемые признаки. При оценке использовались изменённые значения, не только общий контекст.
- 11 сочетаний со сканом получают `comparison_status: unavailable`, `checks.text: unavailable`, пустые изменения и сообщение «Сравнение текста невозможно». PDF/DOCX-отчёт не содержит обычную таблицу diff и не объявляет ноль доказательством отсутствия изменений.

## Проверки кода и упаковки

- Локально: **90 Python-тестов прошли, 1 пропущен** из-за отсутствия PyTorch в окружении тестов. Реальные MiniLM/GLiNER использовались в матрице через сервер моделей.
- Копия только файлов, отобранных в Git, без runtime/models/пользовательских документов: **75 тестов прошли, 16 пропущены** (15 локальных регрессий требуют отсутствующие пользовательские файлы, ещё один — PyTorch). Это проверка исходников из чистого набора, не установка на другом физическом компьютере.
- **6 JS-тестов прошли**, синтаксис app.js проверен Node.
- Настройка адресов через PowerShell проверена на отдельной копии конфигурации. Локальные адреса сохраняются отдельно от общего settings.json и исключены из Git.
- В публикацию не включены веса, окружения, установочные кэши, пользовательские документы, результаты сравнения и журналы. Распаковщик 7-Zip и шрифт включены с лицензиями; PDF.js/конвертер/Python/модели подготавливает bootstrap.

## Границы

Набор мал и состоит из искусственных договоров. Полнота контрольного списка не означает универсальную точность 100%. Сложные PDF, неоднозначные таблицы, дублирующиеся или изменённые ключи строк, шифрованные документы, настоящие подписи и ГОСТ требуют отдельных проверок. OCR-полигон не интегрирован. Чистая установка на другом физическом Windows-ПК и межмашинная LAN-схема в этом выпуске фактически не воспроизводились; инструкция и конфигурация для этих сценариев подготовлены.

Локальные входные документы и машинные отчёты намеренно не публикуются. Для своих документов используйте `python -m scripts.verify_matrix "путь к папке" --output work/matrix` при работающем сервере. Наличие скана проверяйте по comparison_status, а не по count.

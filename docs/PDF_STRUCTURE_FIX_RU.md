# Восстановление структуры PDF–PDF

## Причина

В отчёте пользователя было 40 записей. Абзацы разбивались по отступу первой строки, продолжения после границы страницы обрабатывались отдельно, а одинаковые колонтитулы участвовали в выравнивании основного текста. Это давало ложные перемещения и раздувало события.

## Изменения

- В извлечении PDF учтён отступ первой строки; новая нумерация явно начинает новый блок.
- Добавлен comparison_server/pdf_structure.py: восстановление продолжения номерного пункта на следующей странице по нескольким признакам (последовательность страниц, незавершённый текст, начало продолжения со строчной буквы). Новые заголовки и законченные пункты не склеиваются.
- Координаты и текст всех частей сохраняются; проверяется неизменность последовательности непробельных токенов основного текста.
- Колонтитулы выравниваются отдельно от основного текста. Одинаковые повторения не создают самостоятельные события. Нормализуется лишь номер в конце подтверждённого повторяющегося шаблона «Стр.»/«Page», причём значение обязано совпадать с физическим номером страницы. Номер договора и ошибочный номер страницы не игнорируются.
- Эмбеддинги получают восстановленные блоки. При сопоставлении блоков после нормализации индексы кандидатов переназначаются по идентификаторам; слияния не используют векторы отдельных старых кусков.
- Существующий структурный diff таблиц и точный текстовый diff сохранены. Новые модели и дополнительные требования к VRAM не добавлялись.

## Результат на пользовательских PDF

Локальное сравнение: 24 записи вместо 40. Перестановка предложения в 1.3 — одно событие; оговорка в 5.1 — одна вставка; три перемещения с перенумерацией — три события; строка таблицы и добавленная лоджия сохранены; ложных событий по колонтитулам нет. При доступных эмбеддингах 10.2 представлен двумя сопоставленными заменами вместо удаления и вставки пункта.

76 тестов прошли. Проверены оба PDF против самих себя, сохранение реальных правок суммы/процента/отрицания/email/ИНН, изменённый заголовок, ошибочный номер страницы, границы нового раздела и координаты объединённых пунктов. Предыдущая пара Word–PDF по-прежнему даёт ноль изменений.

## Границы

Это консервативное восстановление, а не универсальное понимание PDF. Многоколоночный основной текст, сложные таблицы без границ и многостраничные таблицы, нестандартная нумерация и сноски по-прежнему требуют отдельного набора проверок. Автоматическое удаление переносных дефисов не применяется: дефис может быть содержательным. При недостатке признаков блоки остаются раздельными; доступные текстовые правки сохраняются. OCR не добавлен.

Рабочий API: 24 события, ИИ использован; обе замены п. 10.2 подтверждены сопоставлением MiniLM. Результат клиентом получен за 6,489 с, полное выполнение с отчётами — 41,849 с. Классификация выполнялась после публикации доступных изменений.

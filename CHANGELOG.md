# Изменения

## 0.3.1 — 03.11.2026

- Веб-сервер пересылает API-запросы на настроенный сервер сравнения: один адрес для интерфейса, загрузки документов, PDF-просмотра и отчётов. Работает через localhost, LAN и HTTPS-туннель к порту 8080.
- Адрес сервера сравнения задаётся на ПК веб-интерфейса через configure.bat; браузеру доступ к порту 8000 больше не требуется. Прямой режим API сохранён.
- Старый адрес браузера автоматически переводится на новый режим при первом открытии обновления. В настройках есть кнопка возврата к подключению через веб-интерфейс.
- Проксирование передаёт тела запросов и ответов потоком, сохраняет multipart, Range и коды ошибок; недоступность API отображается понятным сообщением. Новых зависимостей и моделей нет.

## 0.3.0 — 02.11.2026

- PDF без доступного текста получает `comparison_status: unavailable`, `checks.text: unavailable` и пустой список правок. Это не означает отсутствия различий. Интерфейс и скачанные отчёты явно сообщают, что текст не проверен.
- В смешанных Word–PDF сравнениях каждая редакция готовится независимо. Word отображается в собственный PDF; его текст не используется как разметка другой редакции. Общая геометрическая форма позволяет одинаково сопоставлять пункты, колонтитулы и перемещения. Для Word–Word сохраняется сравнение исходной структуры Word и ранняя публикация списка изменений.
- Уникальный ключ строки сохраняет её идентичность при перемещении с одновременным изменением значений. Одно родительское событие содержит старую/новую строку и детали ячеек без двойного подсчёта.
- Добавлена настройка адресов через `configure.bat` и локальный конфигурационный файл, исключённый из Git.
- Подготовлены инструкции для одного ПК и разнесённых компонентов в LAN, закреплённые зависимости разработки, GitHub Actions и правила исключения моделей/документов/окружений из публикации.
- При остановке учитывается естественное завершение дочернего Python-процесса после остановки родителя.

Исторические отчёты 0.2.x в docs описывают состояние до этих изменений. Данные проверок выпуска — docs/RELEASE_030_RU.md.

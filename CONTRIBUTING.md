# Разработка

Рабочая платформа комплекса — Windows 10/11 x64. Первый запуск описан в README.md.

Для разработки нужен Python 3.11. Создайте отдельное окружение, установите зависимости командой `python -m pip install -r requirements-dev.txt`. Запустите `python -m pytest -q`. Проверки JS: `node --test tests/document_info.test.mjs tests/document_viewer.test.mjs`.

Тесты ядра не скачивают веса моделей. Проверки GPU и фактических моделей выполняются отдельно в подготовленном окружении сервера моделей. Локальные регрессии на пользовательских файлах пропускаются, если папка «Тестовые файлы» отсутствует. CI проверяет общедоступные синтетические сценарии.

Основные каталоги: `comparison_server` — сравнение/API/отчёты, `model_server` — модели, `web` — интерфейс, `scripts` — установка и диагностика, `shared` — настройки и структуры, `tests` — проверки. `ocr_lab` — отдельный эксперимент, не часть сравнения.

Не добавляйте в Git документы сотрудников, результаты сравнения, журналы, ключи, виртуальные окружения или веса моделей. Собственные адреса серверов задавайте через `configure.bat`: он пишет игнорируемый `config/settings.local.json`.

При изменении алгоритма проверяйте одинаковое содержимое и настоящие правки во всех направлениях DOCX/PDF, сканы без OCR, перестановки с одновременным редактированием, отсутствие двойного подсчёта и корректность статусов отчёта. Изменения зависимостей должны сопровождаться обновлёнными lock-файлами, изменения веса модели — закреплённой ревизией в манифесте.

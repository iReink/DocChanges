# Атлас — сравнение документов

Загрузите согласованную и полученную версии договора, посмотрите изменения на страницах и скачайте отчёт в Word, PDF или JSON.

Поддерживаются **DOC, DOCX и PDF с текстом** в любых сочетаниях. Если PDF состоит из фотографий/сканов страниц, сравнение текста не выполняется: программа сообщает об этом. OCR в основном сравнении отсутствует. Проверяются текст, суммы, реквизиты, сроки и таблицы; границы абзацев и явные переносы — только между Word-файлами. Шрифты, цвета и изображения не сравниваются.

## Что нужно

- Windows 10 или 11, 64-разрядная версия.
- Желательно 16 ГБ оперативной памяти. Видеокарта необязательна: есть режим CPU; он медленнее. Для GPU предусмотрен бюджет около 2–3 ГБ видеопамяти и переход на CPU при нехватке памяти.
- До 20 ГБ свободного места для первой установки с GPU. Для варианта без GPU обычно требуется меньше.
- Интернет при первой подготовке компонентов и скачивании моделей. После успешной установки обычная обработка работает локально.

**Python, Microsoft Word, Node.js и Docker заранее устанавливать не нужно.** Установочные скрипты подготовят компоненты в папке программы. Системный PATH не меняется.

## Скачать программу

1. На [странице репозитория](https://github.com/iReink/DocChanges) нажмите зелёную кнопку **Code → Download ZIP**.
2. Нажмите на скачанный архив правой кнопкой → **Извлечь всё**.
3. Перенесите извлечённую папку, например, в `D:\DocChanges`. Не запускайте программу прямо из архива. Папка должна быть доступна для записи.

В Windows файлы `.bat` могут отображаться без расширения — как «Пакетный файл Windows». Ниже их нужно запускать двойным щелчком.

## Вариант 1. Всё на одном компьютере

1. Откройте папку программы и запустите **`start_all.bat`**.
2. Дождитесь сообщения **«Все приложения готовы»**. При первом запуске скачиваются зависимости, конвертер и модели; это может занять значительное время. Следите за сообщениями и не закрывайте окно до окончания подготовки.
3. В браузере откроется приложение. Если оно не открылось, введите **http://localhost:8080**.
4. Выберите два документа. При желании укажите ФИО для отчёта и отдельные файлы электронной подписи. Нажмите **«Сравнить документы»**.
5. Первый список правок может появиться до завершения обработки. Страницы и категории уточняются позднее. Дождитесь завершения для скачивания итогового отчёта.

Повторный запуск — тот же `start_all.bat`. Исправные модели повторно не скачиваются. Для остановки запустите **`stop_all.bat`** и дождитесь сообщения об остановке всех компонентов. Чтобы запустить снова, используйте `start_all.bat` после завершения остановки.

| Компонент | Что делает | Адрес на этом ПК |
|---|---|---|
| Веб-интерфейс | Кнопки загрузки, просмотр страниц и изменений | http://localhost:8080 |
| Сервер сравнения | Принимает документы и формирует результат | http://localhost:8000 |
| Сервер моделей | Помогает сопоставлять и классифицировать фрагменты | http://localhost:8001 |

Первые два серверных адреса не нужно открывать для обычной работы: используйте веб-интерфейс на порту 8080.

## Вариант 2. Компоненты на разных компьютерах в локальной сети

Компьютеры должны видеть друг друга в одной рабочей сети. На каждом нужном компьютере распакуйте программу и выполните его шаги ниже. Не запускайте `start_all.bat` на всех машинах: запускайте только нужный компонент.

Пример адресов, **их нужно заменить своими**:

- **ПК моделей:** `192.168.1.30`.
- **ПК сравнения:** `192.168.1.20`.
- **ПК веб-интерфейса:** `192.168.1.10`.

Адрес компьютера программа печатает в окне запуска в строке «В локальной сети». Также его можно узнать в Windows: **Параметры → Сеть и Интернет → свойства подключения → IPv4**. Если показано несколько адресов и непонятно, какой выбрать, уточните у сотрудника ИТ.

### 1. На ПК моделей

Запустите **`start_models.bat`**. Дождитесь готовности сервера. Веса скачиваются и хранятся только на этом компьютере. Запишите адрес, например `http://192.168.1.30:8001`.

### 2. На ПК сравнения

1. Запустите **`configure.bat`**.
2. В первом поле укажите адрес этого сервера сравнения: в примере **`http://192.168.1.20:8000`**.
3. Во втором поле укажите адрес ПК моделей: **`http://192.168.1.30:8001`**.
4. Запустите **`start_comparison.bat`**. Дождитесь готовности. При первом запуске подготовится конвертер Word; модели на этом ПК не скачиваются.

### 3. На ПК веб-интерфейса

1. Запустите **`configure.bat`**.
2. В первом поле введите адрес сервера сравнения: **`http://192.168.1.20:8000`**.
3. Второе поле на этой машине не используется веб-интерфейсом — оставьте предложенное значение клавишей Enter.
4. Запустите **`start_web.bat`** и откройте **http://localhost:8080**.
5. Если подключение не установилось, нажмите **шестерёнку** в шапке и введите тот же адрес сервера сравнения. Сохранённый в браузере адрес имеет приоритет над настройкой файла.

В конце `configure.bat` предлагает режим моделей. Обычно оставьте автоматический клавишей Enter; вариант **2** запускает модели только на процессоре, без видеокарты.

`localhost` означает **тот компьютер, на котором сейчас открыт браузер**. Для чужого сервера используйте его IPv4-адрес, а не `localhost`.

### Можно обойтись без установки веб-интерфейса у каждого сотрудника

Веб-интерфейс достаточно запустить на одной машине. Например, на ПК сравнения дополнительно запустите `start_web.bat`, предварительно указав в `configure.bat` реальный сетевой адрес API. Тогда сотрудники откроют в браузере **`http://192.168.1.20:8080`**. На их ПК скачивать программу и модели не требуется.

Аналогично можно оставить интерфейс и сервер сравнения на одном ПК, а модели — на другом. Настройте второй адрес через `configure.bat`, затем запустите `start_models.bat` на ПК моделей, `start_comparison.bat` и `start_web.bat` на первом ПК.

### Если сеть не пропускает соединение

- Если Windows спрашивает о доступе приложения к сети, разрешите доступ к **частной рабочей сети**, если это согласуется с правилами организации.
- Скрипты сами не изменяют брандмауэр. В корпоративной сети сотруднику ИТ может потребоваться разрешить входящие соединения: **8080** на ПК интерфейса, **8000** на ПК сравнения, **8001** на ПК моделей.
- Проверьте, что адреса и номера портов не перепутаны. После изменения настроек остановите и снова запустите соответствующие компоненты.
- При смене IP компьютера обновите адрес через `configure.bat` и, при необходимости, в шестерёнке браузера.

Комплекс предназначен для доверенной локальной сети: учётных записей и разграничения доступа здесь нет. Не публикуйте эти порты в интернете.

## Остановка, перенос и обновление

- На каждой машине **`stop_all.bat`** останавливает только компоненты этой копии программы. Остальные ПК он не затрагивает.
- Для переноса уже подготовленной установки скопируйте **всю папку**, включая `runtime`, `models` и `vendor`. Окружения проверятся и при необходимости восстановятся. Модели и скачанные установочные файлы сохранятся; на новом аппаратном профиле может понадобиться интернет. Настройки локальной сети задайте заново для новой схемы.
- Для обновления из GitHub остановите программу и перенесите новые исходники поверх установленной папки, сохранив `runtime`, `models`, `vendor` и `config/settings.local.json`. Повторно запустите нужные компоненты. Не скачивайте обновления поверх работающего сервера.
- Документы и результаты временные: после 30 минут без активности задача удаляется; открытый результат продлевает срок. При перезапуске сервера предыдущие задачи очищаются. Нужные отчёты скачайте заранее.

## Если что-то не работает

| Проблема | Что сделать |
|---|---|
| Первый запуск долго ничего не открывает | Дождаться скачивания и проверки компонентов, читать сообщения окна. Модели скачиваются один раз |
| Ошибка скачивания | Проверить интернет и свободное место, повторить запуск. Готовые компоненты сохраняются |
| Сервер не подключён | Проверить, что нужный `.bat` запущен, указать адрес и порт через шестерёнку |
| Порт занят или запущена старая версия | Дождаться `stop_all.bat`, затем запустить нужные компоненты. Чужой процесс скрипт не останавливает |
| Не хватает видеопамяти | Есть автоматический переход на CPU. Либо запустите configure.bat, оставьте адреса клавишей Enter, выберите режим 2 и перезапустите сервер моделей |
| Скан не сравнивается | Загрузить PDF с выделяемым текстом или DOC/DOCX. Основной комплекс не выполняет OCR |
| Результат исчез | Повторить загрузку: сервер перезапущен или истёк срок хранения |

Запустите **`diagnose.bat`**: он проверит компоненты и покажет сообщения. Технические журналы находятся в `logs`. При обращении за помощью передайте текст ошибки; документы для этого отправлять не нужно.

## Для разработчиков и ИТ

Сервер сравнения имеет API: документация **http://localhost:8000/docs**. Сервер моделей: **http://localhost:8001/docs**. Порты и адрес прослушивания настраиваются в `config/settings.json`; персональные переопределения `configure.bat` хранит в `config/settings.local.json`. [Примеры API](docs/API_EXAMPLES.md), [разработка и тесты](CONTRIBUTING.md), [сторонние компоненты](docs/THIRD_PARTY.md), [диаграмма](docs/process.svg).

В GitHub хранятся исходники, установочные скрипты, закреплённые зависимости и небольшие необходимые ресурсы. **Веса моделей, Python-окружения, скачанные установщики, журналы, документы пользователей и временные результаты не публикуются.**

Каталог [ocr_lab](ocr_lab/README_RU.md) — отдельный эксперимент Xiaomi-OCR-0. Он не входит в три основных компонента, не запускается через `start_all.bat` и не добавляет OCR в сравнение. Для обычной установки действия из его инструкции не нужны.
